\subsection{Linneus' binomial classification rules}

\begin{enumerate}
    \item The entire 2-part name must be written in italics.
    \item The genus name must be written first.
    \item The genus name must be capitalized.
    \item The specific epithet is never capitalized.
\end{enumerate}
